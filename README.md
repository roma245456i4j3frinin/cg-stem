# cg-stem
Аналіз та обробка зображень класичними методами. STEM-проєкт з дисципліни "Комп'ютерна графіка та візуалізація".
Усі методи реалізовані через NumPy. Pillow потрібен лише щоб читати і зберігати файли.

## Вибірка
105 супутникових знімків (256x256) з UC Merced Land Use Dataset, джерело: https://vision.ucmerced.edu/datasets/

## Методи
| Метод | Категорія | Опис |
|---|---|---|
| `hist` | гістограмний аналіз | вирівнювання гістограми |
| `sobel` | сегментація | виділення країв оператором Собеля з порогом |
| `otsu` | сегментація | бінаризація методом Оцу |
| `morph` | морфологія | дилатація вікном 3x3 |
| `lbp` | аналіз текстур | локальні бінарні шаблони |

Метрики якості: MSE, PSNR, SSIM (результат порівнюється з оригіналом без шуму).
Шум: gaussian і salt_pepper

## Структура проєкту
```
stem.py        методи, шум, метрики, меню запуску
config.json    параметри методів і шуму
images/        вхідні зображення
results/       результати (створюється при запуску)
README.md
```

## Запуск
Python 3.10 або новіший.
```
pip install numpy pillow
python stem.py
```

У меню обирається метод (або всі), після цього шум (без шуму, Gaussian, Salt або pepper). 
Програма обробляє всі зображення з images/. Пошкоджені файли і зображення менші за 3x3 пропускаються з повідомленням.

## Параметри config.json
| Параметр | Значення за замовчуванням | Опис |
|---|---|---|
| `seed` | 0 | seed генератора шуму, результати відтворювані |
| `sobel_threshold` | 100 | поріг сили краю для `sobel` |
| `gaussian_sigma` | 20 | стандартне відхилення gaussian шуму |
| `salt_pepper_amount` | 0.05 | частка пікселів, що стануть чорними або білими |

Параметри змінюються без правки коду.

## Результати
Для кожного проходу створюється папка results/<метод>[_<шум>], наприклад results/otsu_gaussian/:
- image(номер).png - оброблені зображення;
- metrics.csv - колонки image, mse, psnr, ssim для кожного зображення.

## Порівняння методів
Середні метрики по 105 зображеннях (результат порівнюється з оригіналом у градаціях сірого, параметри з config.json за замовчуванням):

| Метод | Шум | MSE | PSNR | SSIM |
|---|---|---|---|---|
| hist | немає | 2343 | 15,83 | 0,751 |
| hist | gaussian | 2853 | 14,41 | 0,671 |
| hist | salt_pepper | 3052 | 13,85 | 0,671 |
| sobel | немає | 19250 | 5,46 | 0,000 |
| sobel | gaussian | 19253 | 5,31 | 0,001 |
| sobel | salt_pepper | 19270 | 5,32 | 0,000 |
| otsu | немає | 9807 | 8,48 | 0,479 |
| otsu | gaussian | 10456 | 8,17 | 0,431 |
| otsu | salt_pepper | 9603 | 8,53 | 0,427 |
| morph | немає | 779 | 20,95 | 0,869 |
| morph | gaussian | 1756 | 15,97 | 0,824 |
| morph | salt_pepper | 4697 | 11,77 | 0,425 |
| lbp | немає | 12523 | 7,24 | -0,121 |
| lbp | gaussian | 12599 | 7,19 | -0,067 |
| lbp | salt_pepper | 12494 | 7,24 | -0,108 |

Висновки:

morph найближчий до оригіналу без шуму і при gaussian шумі (SSIM 0,87 і 0,82), але чутливий до salt_pepper - SSIM падає до 0,43.

hist найстабільніший серед методів, що зберігають вигляд зображення: SSIM знижується майже однаково (0,75 до 0,67) враховуючи обидва види шуму.

sobel, otsu і lbp повертають карту країв, бінарну маску і коди текстур, тому порівняння з оригіналом для них не відображає якість методу. Для них низькі значення PSNR і SSIM очікувані, а вплив шуму краще оцінювати як зміну результату відносно запуску без шуму.

sobel з порогом 100 майже не змінює метрики за шуму, бо метрики вже близькі до мінімуму.
